## 선정 논문

### 1. AbdomenNet — 급성 복부 응급 NCCT 파운데이션 모델 (Nature Communications)
다기관 외부 검증(3개 코호트, 2528명)에서 매크로 평균 AUROC 0.919를 달성했고, 판독의 다중 판독자 교차 연구에서 AI 보조가 평균 AUROC를 0.812→0.924로 높이고 판독 시간을 52.5초 단축시켰습니다. 우리 코호트도 5개 기관·9개 장비에 걸쳐 수집되어 기관 간 이질성이 존재하며, 다기관 외부 검증·판독 보조 효과라는 이 논문의 핵심 주제가 우리 데이터 구조와 직접 맞닿아 있습니다. 다만 이 논문은 복부 NCCT를 다루므로 흉부 X선 코호트에 수치를 그대로 적용할 수 없습니다.

### 2. 다기관 폐결절 악성도 추정 딥러닝 모델 비교 (European Radiology)
3개 기관, 269개 결절 데이터셋에서 두 딥러닝 모델이 기관별 AUC 0.71~0.76의 안정적 판별력을 보이며 임상 표준 Brock 모델(AUC 0.55~0.74)을 능가했습니다. 우리 코호트에서 Nodule 소견은 272건 중 7건에 불과한 희소 클래스이지만 5개 기관에 분포하고 있어, 이 논문이 다루는 기관별 성능 편차 문제가 방법론적으로 관련됩니다. CT 결절 악성도 추정과 흉부 X선 소견 분류는 모달리티가 달라 정량 수치는 직접 대응되지 않습니다.

### 3. UniMedDiff — 판독 보고서 기반 지식 강화 확산 모델 (npj Digital Medicine)
판독 보고서로부터 11개 폐 병리를 반영한 흉부 X선을 생성하고, 실데이터 1%만 증강해도 전체 데이터 학습에 근접한 다운스트림 분류 성능을 보였습니다. 우리 코호트는 No Finding이 53%를 차지하고 Pneumothorax·Fibrosis 등 희소 소견은 개별로 10건 미만인 심각한 클래스 불균형 상태로, 판독문 기반 소수 클래스 증강 전략이 바로 적용 가능한 상황입니다. 다만 우리 report_text의 서술 스타일과 다중 라벨 동반 소견 조합에서 동일한 생성 품질·다운스트림 이득이 재현될지는 이 논문만으로 확인할 수 없습니다.
