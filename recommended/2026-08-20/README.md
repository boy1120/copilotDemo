## 채택 논문

### 1. CLEAR: an auditable foundation model for radiology grounded in clinical concepts
- **축**: 기관 간 일반화, 판독 근거 설명가능성
- **왜 관련 있는가**: 87만 건 이상의 이미지-보고서 쌍으로 학습된 흉부 X선 파운데이션 모델로, 미국·유럽·아시아 4개 외부 데이터셋에서 검증되었으며 예측을 소견별 기여도로 분해한다. 우리 코호트도 다중 라벨(침윤, 무기폐 등) 판독 검증이 필요해 개념 기반 근거 제시 방식이 참고가 된다.
- **우리 데이터가 확인해줄 수 없는 것**: 153명 규모 단일 기관 데이터라 CLEAR가 보고한 다국가 외부 검증 수준의 일반화는 재현할 수 없다.
- 링크: https://doi.org/10.1038/s41551-026-01741-4

### 2. Grounding Radiology Report Findings into Medical Image Segmentation (CF2Seg)
- **축**: 기관 간 일반화, 라벨/주석 부족
- **왜 관련 있는가**: 픽셀 단위 분할 주석 없이 판독 보고서 텍스트만으로 병변 위치를 학습하는 CF2Seg는, 우리 코호트처럼 텍스트 라벨(findings_label)과 보고서 원문만 있고 분할 주석이 없는 데이터에 바로 적용해볼 수 있는 접근이다.
- **우리 데이터가 확인해줄 수 없는 것**: 전문가 분할 주석이 없어 CF2Seg가 보고한 분할 정확도 수준을 우리 데이터로 직접 검증할 수는 없다.
- 링크: https://doi.org/10.1038/s41746-026-03051-0

### 3. QoQ-Med3: a multimodal reasoning foundation model for clinical analysis
- **축**: 기관 간 일반화, 판독 근거 설명가능성
- **왜 관련 있는가**: 공개 데이터만으로 학습하고도 held-out 외부 기관 데이터셋에 일반화되며 환각률을 44.4% 낮춘 사례로, 단일 기관에서 수집된 우리 코호트의 외부 타당도 평가 설계에 방법론적으로 참고할 만하다.
- **우리 데이터가 확인해줄 수 없는 것**: 흉부 X선 단일 모달리티만 보유해 초음파·유방촬영 등 다중 모달리티 성능 향상은 확인할 수 없다.
- 링크: https://doi.org/10.1038/s41746-026-02945-3
